# MikcleGrok's Scoop bucket

Scoop bucket for [MikcleGrok](https://github.com/MikcleGrok) tools.

## Usage

```powershell
scoop bucket add mikclegrok https://github.com/MikcleGrok/scoop-bucket
scoop install mikclegrok/openrouter-model-tracker
```

## Apps

| App | Description |
|---|---|
| [openrouter-model-tracker](https://github.com/MikcleGrok/openrouter-model-tracker) | Compare AI models on OpenRouter by quality and price |

Manifests are generated and published automatically by
[openrouter-model-tracker](https://github.com/MikcleGrok/openrouter-model-tracker)'s own release
tooling (`scripts/scoop-manifest.sh`) — do not edit `bucket/*.json` by hand.
